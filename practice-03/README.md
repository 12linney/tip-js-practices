## Организация кода

- `task-service.js`: функции ПР2 (поиск, смена статуса, удаление, сводка), без обращений к DOM.
- `task-selectors.js`: `getVisibleTasks` отбирает задачи по фильтру `all`/`pending`/`completed`, не изменяя входной массив.
- `task-view.js`: создание карточек (`createTaskElement`), отрисовка списка, сводки и пустого состояния; весь текст назначается через `textContent`.
- `main.js`: хранит состояние и обрабатывает события.

Полный список задач хранится в `currentTasks`, выбранный фильтр в `currentFilter`; видимая выборка вычисляется отдельно в `renderApp`. События списка и фильтров обрабатываются делегированием (один обработчик на `ul#task-list` и на `#task-filters`, `closest` для поиска кнопки). Сводка считается в `renderSummary` через `getTaskStats(currentTasks)` по полному массиву.
