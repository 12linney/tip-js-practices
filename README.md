## Задание 1

В ходе выполнения задания один и тот же JavaScript-файл был запущен двумя способами:
- через Node.js;
- через браузер.

Результаты выполнения:  
Node.js - код выполняется в среде Node.js, объект document отсутствует  
Браузер - код выполняется в браузере, объект document доступен

Различие: браузер предоставляет дополнительные API для работы со страницей, а Node.js работает вне браузерной среды
